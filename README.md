# Water Street Tavern — website redesign preview

Static redesign preview for The Water Street Tavern, 324 South Water Street, Stoughton, WI.
Content and photos are from waterstreettavernstoughton.com; menus transcribed from the restaurant's PDFs (also linked in `/menus`).

Build: `python3 src/build.py` regenerates all HTML pages from `src/build.py` + `src/menus.py`.
